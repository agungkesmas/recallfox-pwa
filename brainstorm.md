## Arah Ide
RecallFox PWA adalah companion mobile/web untuk RecallFox: sinkronisasi penuh
via Supabase sehingga semua data dari addon (prompt, konteks, snapshot,
screenshot, dokumen, link, bundle, catatan) muncul di HP dan sebaliknya.

## Value Proposition
Akses dan input data RecallFox dari mana saja (HP), sinkron otomatis lintas device.

## P0 (inti, sudah ada)
- Media: capture/scan/annotate/compress/batch download
- Vault: search/filter/sort/favorite/batch
- Notes: rich text, 12 warna, auto-sync
- Sync penuh dengan addon Firefox & Chrome via Supabase
